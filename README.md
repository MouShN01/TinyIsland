# TinyIsland

TinyIsland is a short Unity survival-arcade prototype about a tiny castaway collecting driftwood during low tide, building a tower, and surviving rising tides.

## Core Loop

Gather → React to Tide → Build → Climb → Survive → Escalate

## Engine

Unity: v.6000.4.0f1
Render Pipeline: URP

## Project Goals

- Build a complete 5–10 minute prototype
- Demonstrate core loop design
- Implement tide-based environmental pressure
- Implement tower progression and timing-based climbing
- Keep scope controlled
